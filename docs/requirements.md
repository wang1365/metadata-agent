# 元数据分析智能体需求说明

状态：第一版设计基线，尚未实现本文描述的服务功能。

更新日期：2026-10-10。

配套文档：[技术架构](architecture.md) · [项目入口](../README.md)。

## 1. 目标与用户

将当前 DSH Python 命令行示例扩展为元数据分析后端服务。用户可以上传系统的数据字典 Excel，或直接连接 MySQL，由智能体探索表、字段、键、实体关联和加工血缘，并通过 REST API 和测试界面查看、审核、查询与导出结果。

DSH 是唯一智能体运行时，且承担全部分析：Excel 布局识别、字典解读、键与关系分析、ER、SQL 血缘、影响分析及问答。MCP 工具由 DSH 插件实现和加载，只提供原始证据读取、受控查询及结构化结果交付。Python 服务只负责接口、任务生命周期、人工确认、结果校验和存储，不实现分析算法或 Agent 循环。

| 用户 | 主要需求 |
| --- | --- |
| 数据库及系统开发人员 | 了解数据库设计，发现缺失约束和候选关联 |
| 数据分析及治理人员 | 查看对象含义、加工依赖及上下游影响 |
| 测试与集成人员 | 用界面和 REST API 验证上传、连接、分析及问答全流程 |

## 2. 第一版范围与术语

### 2.1 范围

- Excel 和 MySQL 是两个独立入口，可以单独使用；第一版不做跨入口的对照或自动合并。
- 支持 MySQL 8.0/8.4，预留数据库连接器接口；其他版本报告兼容性告警，不计入第一版验收范围。
- 支持复杂 Excel 布局的自动识别、预览修正和人工确认。
- 支持受限只读数据验证，以及有限原始样本向百炼发送。
- 提供 ER 图、血缘图、元数据浏览、关系审核、元数据问答和结果导出。
- 以本地或单机测试为部署目标，默认一个任务运行，其余排队。

### 2.2 术语与结果分类

| 术语 | 定义及展示要求 |
| --- | --- |
| 数据源 Source | 一份 Excel 或一组 MySQL 连接及选定对象范围 |
| 分析任务 AnalysisJob | 一次分析执行，包含状态、阶段、预算、告警及失败原因 |
| 元数据快照 Snapshot | 一次分析发布的结构化结果，问答与导出均绑定快照 |
| 声明关系 | Excel 明确说明或数据库约束明确记录的键与关联；保留声明来源，不把字典声明视为数据库实际约束 |
| 推断关系 | 基于命名、类型、注释、索引或模型语义判断的候选关联 |
| 采样验证 | 在有限查询范围内获取支持或反驳候选关系的证据，不能证明全量唯一性或引用完整性 |
| 加工血缘 | 数据经过查询、表达式或加工从源对象流向目标对象的依赖；与外键关联分别保存 |
| 证据 Evidence | Excel 单元格范围、约束名称、SQL 片段、采样范围或验证指标等可追溯依据 |

置信等级使用高、中、低及解释，不将模型判断包装成统计概率。人工确认与证据来源分别记录，确认候选关系不会将它改写为数据库约束。

### 2.3 第一版非目标

- 不自行开发 Agent Runtime，不引入第二套 Agent 框架。
- 不做多租户、用户登录、权限平台或公网部署。
- 不做 Excel 与数据库结果自动合并、跨系统 ETL 或代码仓库接入。
- 不保证恢复动态 SQL 的实际运行血缘，不承诺任意 Excel 全自动准确识别。
- 不执行宏，不做图片 OCR，不修改源数据库结构或业务数据。
- 不把 ER 关联、字段同名或业务相似性直接当作确定的加工血缘。

## 3. Excel 数据字典入口

### R-EXCEL-01 上传与检查

支持 `.xlsx` 和 `.xls`。上传后返回数据源 ID，保存原始文件并检查文件类型、大小和解析可行性。扩展名与实际格式不符、损坏、加密或超出限制时返回明确错误，不进入模型分析。

### R-EXCEL-02 布局探索

支持一表一 Sheet、单 Sheet 字段清单、多级合并表头、同 Sheet 多个表块、说明页和中英文表头。工具提取单元格、坐标、合并区域及必要格式信息，DSH 分块读取并识别表名、字段、类型、键和说明。

不一次性将整个工作簿作为模型上下文。空白区域不作为有效数据，无法识别或有歧义的区域必须列出告警。

### R-EXCEL-03 预览、修正与确认

展示原始表格区域与结构化草稿，允许用户修正表块范围、表头映射、表名和字段。正式关系分析前必须确认解析结果，等待确认期间释放运行资源。

确认后继续同一分析任务，但使用独立的一轮 DSH 执行读取已确认草稿；不得因继续分析而覆盖用户修正。

### R-EXCEL-04 结果与证据

每个识别对象可定位到文件、Sheet 和单元格范围。复合主外键保留有序字段组。仅有数据字典时可以发现关联候选；缺少 SQL 或明确加工说明时，不生成确定血缘。

## 4. MySQL 入口

### R-DB-01 连接与范围

支持填写连接参数、测试连接、选择数据库及表范围。密码不在 API 响应、界面回显或模型提示词中返回。使用具备所选范围只读权限的账户。

创建 MySQL 分析前必须显式勾选 1–500 张表/视图。候选可来自超过 500 张表的数据库，按表名不区分大小写的包含片段（模糊匹配）或正则表达式筛选，先过滤完整候选集再分页。每页 50 项，支持单项、当前页和全部匹配项勾选，跨页/切换条件保留选择，可查看/移除已选项、清空和刷新。展示匹配数、全库数和已选数；全部匹配项超过 500 或合并后超过 500 时拒绝批量选择，不能静默截断。无选择不能提交，不再将空列表解释为新建全库任务；要分析全库也需显式勾选。Excel 流程不变。

筛选文本最多 256 字符；无效正则和超过 200 毫秒匹配预算明确报错。提交前验证重复项及对象存在性，过期对象要求刷新后重选；重试保留原范围。DSH 工具及结果写入强制限定已选范围，不自动采集范围外表或全库例程/触发器。跨范围外键/SQL 引用保留原始证据并由 DSH 告警，范围外端点不进入本次图；需用户扩大选择另建任务。

验收：含 751 个对象的候选目录能筛选并选中第 500 项之后的对象；分页不影响过滤总数；模糊/正则匹配一致且无效/超时可恢复；选中范围经 REST、重试及 MCP 保留，范围外采集、查询和结果写入被拒绝。

### R-DB-02 结构采集

采集表、视图、字段、类型、默认值、可空性、注释、主键、唯一约束、外键和索引。约束支持复合字段，数据库与 schema 命名保留原始标识。

读取权限允许的视图、存储过程及触发器定义。定义不可见时记录权限或能力缺失，其他采集可以继续，但最终必须说明覆盖范围。

### R-DB-03 候选关系发现与验证

由 DSH 结合字段名称、类型、注释、索引及已有键提出候选关系，必要时调用 MCP 获取空值、唯一性、引用匹配等指标。

工具强制限定对象范围、查询类型、次数和时长。不运行 Agent 自由生成的 SQL，不调用存储过程，不执行 DDL、DML 或带副作用的查询。不能只靠提示词约束只读行为。

候选关系须包含验证范围、方法、指标和结论。预算耗尽或查询超时后保留未验证候选，不自动改为无限制全表扫描。有限样本的高匹配率只能作为支持证据。

### R-DB-04 血缘

DSH 根据插件采集的原始定义和结构证据分析视图 SELECT 的表级与字段级血缘，包括 JOIN、CTE 和能够明确理解的表达式；存储过程和触发器只分析可由定义证据确认的加工依赖。动态 SQL、语义歧义或定义不可见时标记未知并保留原因。不使用 Python SQL 血缘解析器；服务只校验和保存 DSH 提交的结果。

不能将“未发现血缘”展示为“确认不存在血缘”。

## 5. 结果、交互与对外服务

### R-RESULT-01 元数据与关系审核

支持搜索表字段，查看键、类型、注释、证据和告警。关系可按来源、置信等级和审核状态筛选。人工可确认、驳回或更正候选关系；保存审核时间、说明和变更记录，保留原始发现及证据。

### R-RESULT-02 ER 图与血缘图

ER 图展示表、字段和键关联；血缘图独立展示加工依赖，支持表级和字段级切换、上下游探索、搜索定位及证据查看。

默认展示选中对象及一跳邻居，按需展开，避免一次渲染全部字段。通过线型、文字标签及颜色共同表达来源和审核状态，不能仅靠颜色区分。

### R-QA-01 元数据问答

问答绑定快照和独立会话。DSH 通过 MCP 搜索对象、遍历关系和读取证据，回答结构、关联及影响分析问题；回答引用可跳转到对应表、字段、边或原始证据。

证据不足时说明不确定性。问答默认只读取已采集元数据，不新增业务查询，不自动触发数据库重新分析。

### R-EXPORT-01 导出

支持完整结果 JSON、表字段及关系 CSV，以及当前图的 SVG/PNG。导出携带快照标识、关系来源、审核状态和证据引用，不包含数据库密码或原始业务样本。

### R-SERVICE-01 REST API 与任务

提供 `/api/v1` REST API 和 `/docs`。分析及问答采用异步任务，返回 `202` 和任务 ID。支持状态查询、告警查看、取消及显式重试。前端默认每两秒查询一次进度。

状态为排队、运行、等待确认、成功、部分成功、失败、取消。阶段进度是实际阶段及计数，不伪造模型思考百分比。部分成功须列出缺失能力和失败对象。

分析成功必须有合法已发布快照；问答成功必须有已保存答案及合法证据引用，不能仅依据模型说“完成”判断成功。

### R-SERVICE-02 本地调试入口

提供 Bash 脚本同时启动 Python 封装服务 `metadata_service`、独立 Worker 和测试前端。前端与 API 支持开发热更新，插件/Skills/Worker 修改后显式重启。默认前端 5173、API 8000，支持环境配置端口与分进程日志；正常退出回收所属进程树。该服务不是独立 Agent，全部分析仍通过 DSH 完成。

### R-SERVICE-03 任务过程日志

分析和问答任务提供可实时读取的过程事件：排队、领取、环境准备、DSH 初始化、MCP 就绪、DSH 请求、模型消息、工具开始/结束/失败、结果保存、发布、取消、超时和中断。工具事件带名称、耗时及安全错误码；阶段随实际事件更新，不用虚构百分比。

前端任务列表提供“过程日志”，运行中每 2 秒按游标增量读取，支持级别与文本筛选、跟随最新、手动刷新及当前窗口下载。终态补读最后事件后停止定时请求。服务每任务保留最近 5000 条，前端窗口最近 2000 条；超限明确提示，旧版任务不能补录未采集的历史。

Worker 每 15 秒记录一次运行进程心跳，表示进程仍在运行，不等同于模型正常响应。后端将安全事件输出到 stderr/本地日志，Bash 开发入口同步展示 Worker 转发的事件。日志不得包含凭据、原始工具参数/结果、SQL 内容、业务样本、模型上下文或推理内容；只展示固定摘要、计数和白名单错误码。

DSH 结束状态必须区分正常结束、输出达到上限、模型错误、取消和缺少结束事件；任务错误与日志保留具体安全错误码，不统一隐藏为 DSH_TURN_FAILED。达到输出上限不等于成功，也不得由 Python 自动启动模型续写循环。交付工具公开完整结构 Schema，拒绝额外根字段；支持小批合并保存，降低全量结果反复重写导致的输出超限风险。

## 6. 默认限制与数据处理

以下为第一版设计默认值，配置变更须同时更新 API 校验、界面提示和测试。

| 项目 | 默认值及行为 |
| --- | --- |
| 文件 | 单次 Excel 最大 20MB；另设解压体积与有效单元格保护，不以压缩大小作为唯一依据 |
| 对象规模 | 每次最多 500 张表、20,000 个字段；超出时要求缩小选择范围 |
| 并发 | 单个 Worker 同时运行 1 个任务，其余持久化排队 |
| 数据验证 | 每个分析任务最多 30 次业务数据查询，指标、关系验证与样本查询共享预算 |
| 本地采样 | 单次查询最多 1,000 行；明确采样方法及其局限，不把 LIMIT 结果称为随机样本 |
| 向模型发送样本 | 默认关闭，用户显式启用才允许原始值；每次最多 20 行、每值最多 200 字符、每任务累计最多 200 行；可关闭 |
| 工具与模型超时 | 必须有有限且可配置的连接、查询、工具和 DSH 请求超时；具体配置见架构文档 |
| 默认监听 | `127.0.0.1`，仅用于本地或受控单机测试 |
| 本地敏感数据 | 上传文件、连接密码、DSH 日志、样本和运行产物均不得提交 Git |

样本不写入正式元数据结果，但作为工具返回内容可能进入 DSH 本地会话日志。界面明确说明样本发送范围和累计量，提供任务数据清理入口；清理不得影响其他任务。

百炼 Key 使用本地 `.env` 或启动环境配置。动态数据库密码加密保存，主密钥优先通过本地环境配置提供；单机测试未设置时生成被 Git 忽略的本地密钥文件，备份与权限要求见架构文档；日志与错误信息不输出连接密码或完整连接串。

## 7. 验收与异常场景

| 编号 | 场景 | 验收结果 |
| --- | --- | --- |
| A-01 | Excel 多 Sheet、合并表头、多表块、中英文表头 | 能生成草稿，证据坐标准确，未识别区域可见 |
| A-02 | 解析有歧义、字段缺失或重复 | 可修正并确认；继续分析不覆盖人工修正 |
| A-03 | 损坏、加密、伪装或超限 Excel | 可理解的错误，无无限解析或模型调用 |
| A-04 | MySQL 单列键、复合键、显式外键 | 采集准确，字段组与顺序保留 |
| A-05 | 未声明关联、孤儿引用、同名无关字段 | 候选与已声明约束分开，采样指标可追溯，无“同名即关联”结论 |
| A-06 | 视图 JOIN、CTE、表达式字段 | 可核对表级与字段级血缘，关联不误当加工血缘 |
| A-07 | 动态 SQL、定义权限不足或解析失败 | 标记未知或缺失，允许部分成功，不伪造血缘 |
| A-08 | 查询超时、预算耗尽、数据库断连 | 中止受影响操作，保留阶段结果并说明未覆盖范围 |
| A-09 | 模型输出不合法、工具出错或模型声称完成 | 工具返回校验错误；没有合法发布结果时不误报成功 |
| A-10 | 取消、服务重启、显式重试 | 回收进程；草稿保留；排队任务保留，中断任务不自动重复模型调用 |
| A-11 | 不同任务和问答会话 | 数据源、会话、证据及结果不串用 |
| A-12 | 样本开关及累计预算 | 关闭后不向模型返回业务样本；开启后不超预算，正式导出不带样本 |
| A-13 | 图、问答、审核及导出 | 图可按需展开，答案可追溯，审核保留来源，导出与快照一致 |
| A-14 | 运行时与分析边界 | 全部分析及 Agent 循环由 DSH 执行；MCP 工具属于 DSH 插件；Python 服务无分析器，工具不生成关系/血缘结论；服务 Agent 无 shell、自由 SQL 或无关工具 |
| A-15 | 文档一致性 | 代码、需求、架构、相关 README 与 Skills 同次更新；实现与验证状态可核对，遵循 agent.md |
| A-16 | 过程可观测性 | 前端与后端能看到同一任务的安全阶段事件；工具耗时和失败可定位，分页不串任务，重启后可读历史；并发日志与晚到事件不覆盖终态，日志不泄漏参数或样本 |

验收使用固定 Excel 夹具和独立 MySQL 测试库，不依赖真实业务库作为自动测试前提。必须完成 Excel 与 MySQL 两条端到端流程；实现与测试顺序见[技术架构](architecture.md#9-测试与实施顺序)。
